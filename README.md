# Candy W 上帝导演

用于 SillyTavern 单角色聊天的剧本导演扩展。支持故事创作、可编辑章节、途中插入章节、角色数值与熟练度技能，以及可恢复的剧情推进。

**[阅读用户说明](PLAYER_GUIDE.md)**

当前版本：3.1.0。最低客户端版本：SillyTavern 1.18.0。

## 组成

- 根目录及 `src/`：酒馆前端扩展。
- `server/`：配套服务端插件，独立处理导演接口请求。仅安装前端不足以使用导演功能。
- `tests/`：模拟接口的隔离测试，不是实际模型验收。
- `tools/`：带基线核对和备份的升级、回滚工具，面向已有安装，不是首次安装向导。

导演接口和酒馆正文接口分别设置。请参阅用户说明完成使用配置。已有旧版安装应先备份并按配套升级流程迁移，不要仅覆盖前端。

## 开发验证

在具备 Node.js 和 npm 的环境运行 `npm run verify`，执行静态检查和模拟测试。

仓库不分发用户设置、聊天、旅程存档、接口凭据或本地排查记录。演示场景和测试使用程序内置或模拟内容。
