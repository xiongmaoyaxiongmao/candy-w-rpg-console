# Candy W 跑团控制台 v1

给 SillyTavern 的单人跑团扩展：你是一名玩家，当前聊天正在使用的 AI 继续保持自己的角色卡、人设、关系、世界书和前文，同时主持场景、NPC 与判定。

它不配独立 API、不保存 Key，也不会替换角色卡、读取/复制世界书、改写聊天正文或改变你的模型连接。

## 安装或更新

在 SillyTavern 的“安装扩展”中粘贴：

```text
https://github.com/xiongmaoyaxiongmao/candy-w-rpg-console
```

已安装旧版时，在 SillyTavern 的扩展管理里点“更新”后，按提示重载/刷新页面，再开一团新的 v1 团务。SillyTavern 1.18.0 的更新只会更新文件并提示 “Reload the page to apply updates”；不重载时，页面仍在运行旧版 v0 的 JS 和提示词。**v0.x 是实验版，v1 不读取、迁移或继承它的团务状态。** 旧聊天 metadata 不会被本插件删除。

## 第一次这样玩

1. 打开你要玩的角色聊天，点右下角的“🎲 跑团”。
2. 点“开新团”，填团名、题材、玩家角色和想玩的感觉；当前目标可先留空。
3. 点“建立这一团”，再点“开始第一幕”。这是一次你明确点击触发的 SillyTavern 标准生成；AI 会自然承接已有聊天，只有空白聊天才建立第一幕。
4. 像平常一样说你的自由行动。AI 遇到不确定结果会提出属性、骰子公式和难度。
5. 到“判定”页公开投骰：骰子总和加所选属性，对照难度。投完点“按最近判定继续”。
6. 在“团务”页维护场景、目标、三项属性（体魄/洞察/意志）和状态；在“记录”页确认线索、物品、重要 NPC。

每个聊天各自保存一团。导入只写进当前聊天，导入前会校验 v1 文件格式；结束本团会停止注入，但保留记录让你导出。

## 主持与上下文

每次 AI 请求都使用 SillyTavern 正常的生成链，因此角色卡、已激活世界书、persona、scenario、Author’s Note（若启用）和聊天历史仍由酒馆原生编译。插件只通过一个固定注入槽补充主持契约、当前团状态和最近判定；关闭插件或结束本团时该槽会清空。

“成熟关系剧情”允许成年人之间自然的暧昧、亲密与关系张力。插件不含剧情关键词过滤、内容规避规则或供应商绑定。

## 边界

- 单人玩家 + 当前单个角色聊天 AI 主持；群聊会直接提示不支持，不会保存团务、注入上下文或请求生成。也不含多人、地图、战棋或战斗引擎。
- 线索、物品、NPC 与状态由玩家确认后手动记录；插件不会自动解读剧情。
- 未在用户真实酒馆安装验收；发布前以 SillyTavern 1.18.0 本机源码、fake adapter 集成测试和桌面/手机夹具渲染验证。
