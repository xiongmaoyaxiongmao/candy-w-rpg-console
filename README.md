# Candy W 跑团控制台

这是一个独立、轻量的 SillyTavern 第三方扩展，用来先试玩 Candy W 需要的单人 AI 主持跑团体验。它不配置独立 API、不保存 Key，始终使用你当前聊天已经连好的模型。

## 安装与启用

将整个 `candy-w-rpg-console` 文件夹放到：

```text
SillyTavern/public/scripts/extensions/third-party/candy-w-rpg-console
```

刷新 SillyTavern，在扩展设置里确认“Candy W 跑团控制台”已启用。本仓库发布包不包含用户酒馆数据，也不会自动连接或上传聊天内容。

也可以在 SillyTavern 的“安装扩展”输入框直接粘贴：

```text
https://github.com/xiongmaoyaxiongmao/candy-w-rpg-console
```

## 第一次这样玩

1. 打开你想玩的角色聊天，点击右下角“🎲 跑团”。
2. 点击“开新团”，填团名、题材、你的角色名和一句想玩的感觉；最后一项可空。
3. 点击“准备第一幕”，再点击“开始第一幕”。这一次明确点击会用当前酒馆模型发送开场请求，AI 就开始主持。
4. 之后正常和 AI 聊行动。她要求判定时，到“掷骰”页掷 `d20`、`2d6+1` 等骰子，把结果告诉她。
5. 线索、物品和重要 NPC 在“记录”页手动记下。每个聊天各自保存一团，可导入/导出。

如果“开始第一幕”按钮提示输入框有草稿，先发送或清空草稿即可；插件不会替你覆盖正在写的内容。

## 边界与验证

- 首次开团后，插件会向当前聊天注入稳定的 AI 主持契约和紧凑团状态；关闭注入或“结束并清空本团”会同时清空两者。
- 状态保存在当前聊天 metadata；没有 DOM/fetch 拦截、关键词成人内容判定或独立 API 配置，也不触碰 World Info、角色卡、预设或其他扩展。
- “成熟关系剧情”只让主持人自然处理成年人之间的暧昧、亲密和关系张力，不替模型生成或审查剧情。

## 后续值得迁入 Candy W 的体验

优先观察：开新团是否足够无门槛、AI 主持是否稳定遵守契约、玩家是否愿意维护少量状态、骰子记录是否真的增加信任感。地图、多人、自动裁决和复杂规则应等真实试玩证明需要后再做。
